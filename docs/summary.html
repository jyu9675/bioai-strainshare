Gut↔Vaginal Strain-Sharing Pilot

BIOAI project · C:\Jeanyu\BIOAI · pilot on public data before the 191-sample paired cohort · Aug 2026
Objective. Validate a modern, contamination-aware strain-sharing pipeline on a public dataset that already shows the signal but never confirmed strain identity — then apply it to our own 191-sample paired vaginal–rectal cohort.

Why this dataset (PRJNA288562)

The shotgun subset of the Goltsman 2018 / DiGiulio 2015 pregnancy cohort: 10 subjects, ~292 samples, paired vaginal + gut + oral, longitudinal. Goltsman found vaginal Lactobacillus/Gardnerella sequences in the gut of 7/10 subjects, with within-subject sequences phylogenetically closer than between-subject.

The gap = our contribution

Goltsman showed related, not identical, strains, on low-depth data, with no contamination control. Takada 2025: no identical gut–vagina Lactobacillus strain has ever been confirmed at strain level.

Primary question: Do any within-person gut–vaginal pairs share the identical strain (popANI ≥ 99.9%), and does the signal survive contamination control? A rigorous positive or negative is publishable. Longitudinal timepoints also let us test directionality (gut-first vs vagina-first) — impossible in our cross-sectional main cohort.

The decision rule

The same logic that flags contamination discriminates it from transmission:

  • Translocation = shared strain (popANI ≥ 99.9%) + dissimilar overall community — one strain moved.
  • Contamination = shared strain + similar whole community (Bray–Curtis) — the whole community leaked.

Rigor comes from a within- vs between-person null: real biology → within-person sharing ≫ unrelated pairs.

Open decisions & caveats

  • popANI threshold: deck uses 99.9%; inStrain canonical is 99.999%. Report both, lock one for consistency with the main cohort.
  • Shallow depth (0.4M reads): only L. iners, L. crispatus, G. vaginalis will reach strain resolution — a thin result table is expected and fine; the pilot proves the method.
  • Compute: heavy steps need a Unix stack (WSL2 / Linux / HPC), not native Windows. Run 01–04 + 07 on the cluster; copy small tables back; run 05–06 on Windows.
  • Manual inputs: reference genome selection and SRA→subject/timepoint/site mapping are the two steps nothing can auto-generate.
